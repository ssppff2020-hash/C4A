## 三、验证：怎么判断这技能真的能用

| 检验 | 命令 / 操作 | 预期结果 |
|------|-------------|----------|
| 可安装 | 解压 `.skill` | 得到 `SKILL.md` + `scripts/` + `references/` 三要素 |
| 可执行 | `python scripts/lesson_design_template.py --topic "X" --audience "Y"` | 打印 8 段式骨架，退出码 0 |
| 可验证 | `python scripts/lesson_check.py 教案.md` | 合格教案 100 分/退出码 0；空骨架 40 分；残缺教案 26 分 |
| 可复用 | 换一门学科（如"激励理论"）跑一遍 | 结构不变，内容随学科变化 |

实测（Python 3.11，Windows 11，零第三方依赖）：

| 输入 | 得分 | 退出码 | 说明 |
|------|------|--------|------|
| `Songpengfei_C4_demo_示例教案输出.md` | **100 / 100** | 0 | 合格教案 |
| 未填充的空骨架 | **40 / 100** | 1 | 检出 5 段仍是占位骨架 |
| 故意做坏的教案（缺段+超时+目标含糊） | **26 / 100** | 1 | 检出 4 项 ❌ |

> 校验器的意义在于**它会报错**。只会打满分的检查器没有价值。

## 四、v1 → v2 改了什么
