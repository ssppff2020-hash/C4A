## 一、这个技能解决什么问题

高校教师与培训师备课有三大痛点：

1. **教学设计结构不完整**：很多教案只写"讲什么内容"，缺少学情分析、目标分层、重难点拆解与评估闭环，教学督导检查时往往被打回。
2. **目标、活动、评估三者脱节**：写了"学生掌握 XXX"，但教学环节里没有对应活动支撑，也没有评估方式验证目标是否达成。
3. **备课耗时巨大**：从零组织一节 45–90 分钟课的教学设计通常需要 2–4 小时，其中大量是重复性的结构化工作。

本技能把"教学设计专家经验"封装成可复用的 AI 工作流：**只要给出课程主题、授课对象、教学目标（可自动拟定）最少 3 项信息，就能在几分钟内得到一份结构完整、目标-活动-评估自洽的 8 段式教学设计草稿**，教师只需在此基础上打磨内容，大幅提升备课效率。

## 二、使用场景

| 场景 | 适用 |
|------|------|
| 日常备课 | 新教师/老教师快速产出教案初稿 |
| 教学检查/督导 | 需要结构完整、要素齐全的教学设计文档 |
| 磨课/说课准备 | 需要学情分析与目标分层的完整逻辑链 |
| 课程思政建设 | 需要在设计中融入思政元素 |
| 混合式教学/慕课 | 需要适配线上线下的环节设计 |
| 教学比赛 | 需要规范的教案格式与评估量表 |

## 三、输入与输出（Clear I/O）

**输入（最少 3 项，其余可选）：**
- 课程主题（必填）
- 授课对象与基础（必填）
- 教学目标（可选，不给则由 AI 自动拟定）
- 可选增强：课时长度、班级人数、教材版本、考核方式、课程思政要求、特殊学情

**输出：** 一份 8 段式完整教学设计 Markdown 文档：
1. 基本信息 2. 学情分析 3. 教学目标（布鲁姆分层） 4. 教学重难点 5. 教学环节设计（5 段式时间轴） 6. 教学方法与手段 7. 教学评估 8. 课后反思与迭代

**外加一份质量校验报告（v2 新增）**：对任意教案做 7 项机械校验，输出 0–100 分与逐条改进建议。

**一句话：输入"课程主题 + 授课对象（+ 可选教学目标）"，输出"8 段式完整教学设计文档 + 质量校验报告"。**

## 五、使用步骤

1. **安装**：将 `Songpengfei_C4_lesson-design-assistant.skill`（ZIP 格式）安装到支持 Claude Skills 的环境；若环境要求 tar.gz，可用附带的 `.tar.gz` 版本。也可直接解压使用 `SKILL.md`。
2. **触发**：对 AI 说："写一份《XX》的教学设计" / "帮我设计这节课" / "lesson plan for ..."。
3. **提供输入**：给出课程主题、授课对象；教学目标可留空。
4. **接收输出**：AI 按 8 段式输出完整教案；对任意部分说"把第 X 环节改成任务驱动"即可局部修订。
5. **自检（v2 新增）**：`python scripts/lesson_check.py 教案.md` → 拿到 0–100 分与逐条改进建议，有 ❌ 就回到对应步骤修改后重跑。
6. **课堂验证**：用文档末尾自查清单核对结构；用真实课堂验证学情【假设】并修正。

## 六、真实案例

**案例：数据结构—栈（45 分钟，计算机专业大二）**

输入："写一份《数据结构—栈》的教学设计，对象是计算机专业大二学生，已学 C 语言。"

技能输出（摘要）：
- 学情分析：已掌握数组/链表，能写简单线性结构程序；对括号匹配等生活化应用兴趣高
- 目标：说出 LIFO 特性（知识）→ 用 C 实现顺序栈操作并解决括号匹配（能力）→ 树立"先设计后编码"工程思维（素养）
- 环节：导入(5') 浏览器后退/括号匹配案例 → 新授(15') 动画演示入栈出栈 → 互动(8') 结对补全 push/pop → 应用(12') 括号匹配任务 → 总结(5') 布置栈转二进制作业
- 评估：课堂提问 + 结对互评 + 括号匹配程序运行结果 + 课后作业，逐条对应三类目标

**校验结果（v2）**：把这份教案丢给 `lesson_check.py`，得 **100 / 100**，7 项全过——
8 段齐全且均已填充、3 条目标均含可测量动词、环节合计 45 分 = 课时 45 分、知识/能力/素养三类目标均被评估覆盖。

作为对照，同一脚本对**未填充的空骨架**判 40 分、对**缺段+超时+目标含糊的教案**判 26 分——
说明校验器会真报错，不是只会打满分。

## 七、可扩展性

- 框架数据（学情维度、布鲁姆动词库、环节模板、6 个学科案例、校验规则、双语术语表）集中在 `references/design_framework.yaml`，新增维度或学科只需改 YAML，不改工作流与脚本。
- 校验规则可通过 `--json` 输出接入 CI：教案仓库每次提交自动跑 `lesson_check.py`，退出码非 0 即拦截。
- 支持双语教案、实验课变体、2 学时连排等边界场景（见 SKILL.md 的 10 条 Edge Cases）。
